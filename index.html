Le préfixe g, en entier

En Normal mode, g ouvre une deuxième couche de commandes : navigation fine, changement de casse, formatage, onglets… Tout ce qui suit se tape juste après le g.

La commande :g — à ne pas confondre avec g

Le préfixe g ci-dessus se tape en Normal mode. :g (raccourci de :global) est tout autre chose : une commande en mode Commande qui exécute une action sur toutes les lignes correspondant à un motif.

anatomie de la commande

:g/motif/commande → pour chaque ligne qui matche motif, exécute commande

exemples courants

:g/TODO/dsupprimer toutes les lignes contenant TODO
:g!/TODO/dsupprimer toutes les lignes sans TODO (ou :v/TODO/d)
:g/foo/s//bar/gremplacer foo par bar, seulement sur les lignes matchées
:g/^$/dsupprimer toutes les lignes vides
:g/pattern/t$copier (t = copy) les lignes matchées à la fin du fichier
:g/pattern/m0déplacer (m = move) les lignes matchées au début
:g/pattern/normal A;exécuter une commande Normal mode sur chaque ligne matchée
:g/pattern/#lister les lignes matchées avec leur numéro
